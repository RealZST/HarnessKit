HarnessKit 直接编辑各个 agent 自己的目录，而不是托管这些目录。无论 HarnessKit 是否在运行，每个 agent 都照常读取自己的文件，使用的也是自己的格式。HarnessKit 读取这些文件，向你显示已安装的内容；你执行安装、启用、禁用或删除操作时，它会写入这些文件。

HarnessKit 自己只有一个重要的文件：`~/.harnesskit/metadata.db`。其中记录的是 agent 文件中无处存放的信息，例如某个 skill 的来源、审计结果。它还保存快照：有些 agent 没有自带的开关，你在这些 agent 上禁用的 MCP server 和 hook 会原样复制一份保存在这里。任何 agent 都不会读取这个文件。

卸载 HarnessKit 时即可看出这种设计的效果：每个 agent 的配置都原样保留。唯一的例外是你之前禁用的内容，[原地管理文件](/zh/docs/how-it-works/in-place/)中逐一列出了这些情况。
