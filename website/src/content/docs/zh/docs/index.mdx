**所有 agent，一个家**。每个 AI 编程 agent 都把 skill 和设置存放在各自的文件夹中。HarnessKit 在一个窗口中显示所有 agent 的 skill、MCP server、plugin、hook 和 CLI，一键即可把 skill 或 MCP server 添加到另一个 agent。安全审计在你自己的电脑上运行，为每个扩展给出信任评分。工具集把 skill、MCP server 和规则保存为一套，一步即可添加到项目中。HarnessKit 免费开源，提供桌面应用，也可以在终端或浏览器中使用。
